# JCDecaux API Playground

## What this project does

Polls the JCDecaux public bike-sharing API and produces two outputs:

1. **Interactive web map** (`docs/index.html`) — Leaflet map with pie chart minicharts per station, updated by a GitHub Action and served via GitHub Pages.
2. **JPEG snapshots** (`images/<city>/`) — Static map images generated by `main.R` during local polling sessions.

The live map is Lyon's Vélov' network. Paris no longer uses JCDecaux.

## File map

| File | Role |
|------|------|
| `velib.R` | Fetches and parses station data from the API. Single function `get_velib_data(city)` returns a data frame; `get_last_update()` extracts a formatted timestamp. |
| `update_index.R` | Generates `docs/index.html`. Run this to rebuild the web map. |
| `main.R` | Polling loop (60 s) for local JPEG snapshot generation. Calls `make_map()` only when the API reports a new timestamp. |
| `maps.R` | `make_map()` — renders circle-marker map and saves as JPEG via `mapview::mapshot()`. |
| `docs/index.html` | Built artifact — do not edit by hand. |
| `docs/experiment/` | Scratch scripts used during development. Not part of the pipeline. |

## Data model (`velib_data` data frame)

Columns returned by `get_velib_data()`:

| Column | Type | Description |
|--------|------|-------------|
| `stations` | int | Station ID |
| `name` | chr | Station name |
| `lng`, `lat` | dbl | Coordinates |
| `last_update` | dbl | Unix ms timestamp from API |
| `pct_free` | dbl | % empty stands |
| `pct_occ` | dbl | % bikes present |
| `pct_ko` | dbl | % out-of-order — clamped to 0 (API sometimes returns bikes+free > total) |
| `pct_max` | dbl | max of the three pct columns |
| `dominant` | chr | Name of the dominant pct column |
| `color` | chr | green / orange / red |
| `n_total` | int | Total dock count |
| `n_free` | int | Empty stands |
| `n_occ` | int | Bikes present |
| `n_ko` | int | Out-of-order docks — clamped to 0 with `pmax(0L, ...)` |

## Web map details (`update_index.R`)

- Tile layer: `CartoDB.DarkMatter`
- Center: Lyon `lng=4.85, lat=45.76`, zoom 14, bounds 13–17
- Pie charts via `leaflet.minicharts::addMinicharts()`:
  - Colors: green (Free) / orange (Occupied) / red (Out of order)
  - Legend labels set via `setNames()` on `chartdata` — the column names become legend entries
- Popup per station (built with `mapply` + `popupArgs`):
  - Bold station name
  - Emoji dock grid, 10 per row: 🚲 occupied · 🅿️ free · 🚫 out of order

## Environment

The API key must be set in `.Renviron` at the project root:

```
JCDECAUX_API_KEY=your_key_here
```

## Running

Rebuild the web map:
```r
source("update_index.R")
```

Start the local polling loop (JPEG snapshots):
```r
source("main.R")
```

## Dependencies

```r
install.packages(c("jsonlite", "leaflet", "leaflet.minicharts", "htmlwidgets", "mapview"))
```
